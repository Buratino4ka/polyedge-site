# Сайт PolyEdge Studio — как выложить бесплатно

## Что внутри

```
site/
├── index.html      главная: услуги, работы, форма заявки
├── spasibo.html    страница «заявка отправлена»
├── privacy.html    политика конфиденциальности (нужна по 152-ФЗ)
├── README.md       этот файл
└── assets/         картинки портфолио
```

Сайт статический: ни базы, ни сервера, ни оплаты хостинга. Форма работает через Netlify Forms
(бесплатно до 100 заявок в месяц), заявки приходят на почту и в личный кабинет.

## Вариант 1 — Netlify Drop (5 минут, форма работает)

1. Открой <https://app.netlify.com/drop>
2. Перетащи **папку `site`** целиком в окно браузера.
3. Через 10–20 секунд получишь адрес вида `random-name-123.netlify.app`.
4. Зарегистрируйся (бесплатно), чтобы закрепить сайт за собой и не потерять адрес.
5. В настройках сайта → **Forms** включи уведомления на `contact.polyedge@gmail.com`.

Проверка формы: заполни её на сайте — заявка появится в разделе Forms.

## Вариант 2 — GitHub Pages (бесплатно, но форма не работает)

1. Создай репозиторий `<username>.github.io`.
2. Загрузи файлы из `site/` (в корень репозитория).
3. Settings → Pages → Branch: `main` → Save.
4. Сайт будет по адресу `https://<username>.github.io`.

Форма на GitHub Pages не отправляет письма — нужен внешний сервис (Formspree, Getform).
Проще сразу Netlify.

## Свой домен

- Домен `.ru` — примерно 200–400 ₽ в год (reg.ru, timeweb).
- В Netlify: Domain settings → Add custom domain → прописать DNS у регистратора.
- До покупки домена сайт живёт на `*.netlify.app` — этого достаточно для звонков и КП.

## Что заменить перед публикацией

| Где | Что |
|---|---|
| `index.html` | телефон, e-mail, Telegram, ссылка на ArtStation |
| `index.html` | цены в блоке «Услуги» — сейчас это ориентир из КП |
| `index.html` | футер: добавить ИНН самозанятого, если нужен |
| `privacy.html` | e-mail для запросов по персональным данным |

## Как менять тексты

Открой `index.html` в любом редакторе (VS Code), найди текст (Ctrl+F) и замени.
Всё оформление — в блоке `<style>` сверху. Чтобы поменять цвет акцента, измени
`--accent: #4c8bf5` на свой.

## Чего пока нет (и это нормально)

- Нет отзывов и логотипов клиентов — появятся после первых 2–3 проектов, тогда добавим блок.
- Нет цен клиентов и названий — по той же причине.
- Нет блога — не нужен, пока не начал приводить трафик.

## Порядок действий на завтра

1. Выложить на Netlify Drop (5 минут) — получишь ссылку.
2. Вставить ссылку в КП (можно отдельной строкой в контактах) и в подпись письма.
3. Проверить форму: отправить тестовую заявку.
4. Дальше — только обновлять работы по мере появления кейсов.
